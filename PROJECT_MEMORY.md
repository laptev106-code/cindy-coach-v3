## 1. Базовый профиль проекта
- **Продукт:** CINDY Focus / CINDY Coach V3 — прогрессивное веб-приложение (PWA) для интервальных тренировок (Cindy benchmark: подтягивания, отжимания, приседания) с адаптивным программным коучем.
- **Технологический стек:** 
  - Чистый **Vanilla JavaScript (ES6+)** и семантический HTML5/CSS3.
  - **Полное отсутствие внешних сборщиков и пакетных менеджеров:** никаких `npm install`, Webpack, Vite, Babel. Код исполняется непосредственно браузером.
  - **Локальный запуск:** `START_CINDY_LITE.bat` (поднимает Python `http.server` на порту 8080: `http://127.0.0.1:8080/index.html`).
- **Связанный специализированный навык:** `cindy-coach` (`C:\Users\Геннадий\.gemini\config\skills\cindy-coach\SKILL.md`).

## 3. Критические инварианты (Что категорически нельзя ломать)
1. **Иммутабельность контрактов:**
   - Состояние тренировки управляется строго через `session_contract_v3.js` (`freeze`, `sanitize`, `apply`). Прямая мутация полей объекта сессии запрещена.
2. **Детерминированность ядра (`coach_core_v3.js`):**
   - Никаких сетевых вызовов, `Math.random()` или сторонних асинхронных зависимостей. Все решения коуча математически воспроизводимы по истории и правилам.
3. **Хеш-целостность релиза:**
   - Проект валидируется через `run_release_integrity_tests.cjs` и контрольные суммы `SHA256SUMS.txt`. При изменении состава файлов манифесты обновляются через `scripts/update_release_manifests.py`.
4. **CSS-токены:**
   - Использовать строго существующие переменные темы (`var(--paper)`, `var(--panel)`, `var(--ink)`, `var(--blue)`). Не хардкодить HEX/RGB цвета в компонентах, чтобы не ломать темную тему (`body.dark`).
