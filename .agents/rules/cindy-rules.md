# CINDY COACH V3 — РЕГЛАМЕНТ РАЗРАБОТКИ ПРОЕКТА

> **Область действия:** Этот файл автоматически загружается средой Antigravity при открытии данного репозитория.

## 1. Стек и ограничения
- **Стек:** Чистый Vanilla JS (ES6+) + семантический HTML5/CSS3.
- **СТРОГИЙ ЗАПРЕТ:** Никаких `npm install`, webpack, vite, babel, сторонних библиотек. PWA должно запускаться непосредственно браузером без сборщиков.
- **Запуск:** `START_CINDY_LITE.bat` (Python http.server на порту 8080: `http://127.0.0.1:8080/index.html`).

## 2. Архитектура и контракты
- **Иммутабельность сессии:** Состояние тренировки управляется строго через `session_contract_v3.js` (`freeze()`, `sanitize()`, `apply()`, `clone()`). Прямая мутация полей сессии запрещена.
- **Детерминизм ядра (`coach_core_v3.js`):** Никаких внешних сетевых вызовов, `Math.random()`, сторонних асинхронных операций. Алгоритм коуча полностью детерминирован и автономен.
- **CSS-токены:** Все цвета и стили используют строго переменные темы (`var(--paper)`, `var(--panel)`, `var(--ink)`, `var(--blue)` и т.д.). Никаких захардкоженных HEX/RGB, чтобы не ломать темную тему (`body.dark`).

## 3. Тесты и верификация
- Команда проверки: `node tests/run_regression_tests.cjs`
- **Эталон (Baseline):** 22 PASS / 4 FAIL.
- **Важно:** 4 теста падают только из-за отсутствия Chromium/Selenium в консоли (`CHROMIUM_BIN`). Логика и приемочные тесты (102 кейса) работают на 100% PASS. Не пытаться «чинить» эти 4 теста изменением кода приложения.

## 4. Память проекта
- Полная карта модулей и журнал решений зафиксированы в [`PROJECT_MEMORY.md`](file:///PROJECT_MEMORY.md) в корне репозитория.

## 5. Мобильный UI/UX Стандарт (Apple HIG / Zero Micro-Text)
- **ЗАПРЕТ МИКРО-ШРИФТОВ (8px–10px):** Текст в кнопках, навигации, полях ввода и подписях обязан быть полноразмерным: базовый текст `15–16px`, кнопки `14–16px`, навигация `12–13px`, бейджи строго `>= 11px`. Приложение должно выглядеть как нативный апп iOS/Android, а не уменьшенная веб-страница.
- **ОЧИСТКА ЭКРАНА «ПРОГРЕСС»:** Запрещено выводить псевдонаучные абстракции («Сила 1440 ед.», «Скорость круга», «Нагрузка/мин», «Ритм пауз», «Регулярность», «Личные рекорды», «Цель 20 кругов», «Динамика»). Экран «Прогресс» содержит ТОЛЬКО:
  1. Честный **Журнал тренировок** (история с датами, кругами и упражнениями).
  2. **Достижения** на **плотном белом фоне** (`var(--panel)`), без прозрачных артефактов.
- **НАГИВНЫЕ АНИМАЦИИ (120 FPS):**
  1. Меню настроек, редактирование профиля и модалки ОБЯЗАНЫ плавно выезжать снизу вверх (Apple Bottom Sheet: `translateY(100%) -> translateY(0)`, `cubic-bezier(0.16, 1, 0.3, 1)`). Запрещено резкое мерцающее появление/исчезновение (`display: none` без transition).
  2. Кнопки времени (10, 20, 30 мин) переключаются с плавной анимацией фона/цвета (`transition: 0.22s ease`).
  3. Все кнопки обязаны иметь тактильный отклик `:active { transform: scale(0.96); }`.

## 6. Единый межплатформенный стандарт AGENTS.md и Anti-AI Slop
- **AGENTS.md:** В корне репозитория находится `AGENTS.md` — главный контракт для всех ИИ-агентов.
- **Манифест Anti-AI Slop:** Запрет шаблонного дизайна (фиолетовые светящиеся кляксы, плоские одинаковые карточки, серый стерильный текст). Интерфейс — тактический спортивный инструмент с 3D-глубиной, концентрическими скруглениями $R_{inner} = \max(4px, R_{outer} - P)$, зонами нажатия $\ge 48\times 48$px в Thumb-Zone и нулевым сдвигом верстки (CLS=0) через `tabular-nums`.
- **7-шаговый цикл (Superpowers):** Бриф $\to$ Архитектура $\to$ TDD-шлюз $\to$ Хирургический diff $\to$ Closed-Loop проверка в терминале $\to$ Обновление манифестов $\to$ Понятный отчет.
