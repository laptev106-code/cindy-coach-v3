# UI/UX Design System 2026: Master Design & Engineering Specification

Синтез передовых мировых дизайн-систем (**Apple HIG 2025/2026**, **Google Material 3 Expressive**, принципов **Linear App**, **Josh Comeau (Layered Shadows)** и **Defensive CSS**). 

Интерфейс обязан выглядеть **дорого, тактильно и кристально чисто**: никакого плоского «мертвого» веб-дизайна 2015 года, никаких грязных размытых теней, никаких вылезающих или наезжающих друг на друга блоков.

---

## 1. Фундаментальные Столпы Дизайна 2026

1. **Tactile Depth (Физический 3D-объем):** Кнопки, карточки и плашки ощущаются как физические полированные объекты с верхней световой фаской (Top Rim Light), мягким градиентом освещения сверху вниз и упругим вдавливанием при тапе.
2. **Defensive Layout (Защитная вёрстка без коллизий):** 100% защита от наездов текста на кнопки, от переполнения контейнеров длинными словами и от перекосов при масштабировании шрифтов.
3. **Chromatic Harmony & Tinted Shadows (Цветные тени):** Тени никогда не делаются плоским грязно-черным цветом `rgba(0,0,0,0.2)`. Тени тонируются цветом подложки и строятся из 3-4 тонких слоев.
4. **Subtle Eased Gradients (Нелинейные градиенты):** Мягкие переходы без грубых полос и стыков, фоновая аура через радиальные меш-пятна.
5. **Concentric Geometry (Концентрическая гармония радиусов):** Вложенные элементы строго следуют формуле $R_{outer} = R_{inner} + Padding$.

## 2. Математическая Сетка Отступов (Spacing & Layout Rhythm)

Все отступы, гэпы и паддинги строятся строго по **4px / 8px модульной шкале**. Хаотичные числа (11px, 13px, 17px, 23px) запрещены.

### А. Таблица Токенов Отступов

| Токен | Значение | Где применяется |
|---|---|---|
| `--space-1` | **4px** | Микро-зазоры между иконкой и текстом, отступ бейджа, внутренний паддинг чекбокса. |
| `--space-2` | **8px** | Зазор между тегами/чипами, расстояние между заголовком и подзаголовком. |
| `--space-3` | **12px** | Внутренний паддинг компактных карточек, зазор между полями формы. |
| `--space-4` | **16px** | Стандартный внутренний паддинг карточки (`padding: 16px`), боковые поля экрана смартфона. |
| `--space-5` | **20px** | Паддинг крупных карточек, модальных шторок, отступ между смысловыми секциями. |
| `--space-6` | **24px** | Отступ между крупными блоками интерфейса. |
| `--space-8` | **32px** | Отступ перед глобальным футером или героем экрана. |

### Б. Иерархия Паддингов (Внешнее всегда больше внутреннего)
* Паддинг экрана: **16px** (на смартфонах).
* Паддинг карточки: **14px – 18px**.
* Зазор между дочерними элементами внутри карточки: **8px – 12px**.
* **Правило:** Внутренний отступ контейнера никогда не должен быть меньше зазора между его детьми.

### В. Концентрические Радиусы (Concentric Radius Formula)
Если карточка с радиусом `R1` имеет паддинг `P`, то радиус вложенного элемента `R2` обязан рассчитываться строго по формуле:
$$R_{inner} = \max(4px, R_{outer} - Padding)$$

```css
/* Пример идеальной концентричности */
.parent-card {
  padding: 12px;
  border-radius: 20px; /* R_outer = 20px */
}
.parent-card .child-avatar {
  border-radius: 8px;  /* R_inner = 20px - 12px = 8px */
}
```
*Нарушение этой формулы создает визуальный диссонанс «кривого зазора».*

## 3. Многослойные Диффузные Тени и Световые Фаски (Layered Diffuse Shadows)

### А. Анатомия Премиальной Тени
Отказ от одной плоской тени. Премиальная тень состоит из **3 независимых световых физических слоев**:
1. **Contact Shadow (Тень контакта):** Очень тонкая, темная, близкая тень прямо под объектом.
2. **Directional Bounce (Направленное рассеивание):** Мягкий диффузный слой, задающий высоту отрыва от стола.
3. **Ambient Halo (Окружающий свет):** Широкая, едва заметная цветная аура.

### Б. CSS-Токены Глубины (Elevations 1–4)

```css
:root {
  /* Светлая тема: тени подмешиваются в теплый графит или оттенок темы */
  --shadow-color: 28deg 18% 15%; /* Базовый HSL-тон для реалистичной тени */
  
  /* Уровень 1: Чипы, маленькие кнопки, плоские карточки */
  --elevation-1:
    0 1px 2px hsl(var(--shadow-color) / 0.05),
    0 3px 6px -1px hsl(var(--shadow-color) / 0.08);

  /* Уровень 2: Основные карточки списков, кнопки действия */
  --elevation-2:
    0 1px 2px hsl(var(--shadow-color) / 0.04),
    0 4px 10px -2px hsl(var(--shadow-color) / 0.08),
    0 12px 24px -4px hsl(var(--shadow-color) / 0.07);

  /* Уровень 3: Парящие меню, выпадающие списки, Sticky Bottom-Nav */
  --elevation-3:
    0 2px 4px hsl(var(--shadow-color) / 0.03),
    0 8px 18px -2px hsl(var(--shadow-color) / 0.08),
    0 20px 36px -6px hsl(var(--shadow-color) / 0.12);

  /* Уровень 4: Модальные шторки (Bottom Sheets), всплывающие диалоги */
  --elevation-4:
    0 4px 8px hsl(var(--shadow-color) / 0.04),
    0 16px 32px -4px hsl(var(--shadow-color) / 0.12),
    0 32px 64px -8px hsl(var(--shadow-color) / 0.16);
}

:root[data-mode="dark"] {
  /* Темная тема: глубокие чернильные тени с подсветкой контуров */
  --shadow-color: 0deg 0% 0%;

  --elevation-1: 0 2px 6px rgba(0, 0, 0, 0.35);
  --elevation-2: 0 4px 14px rgba(0, 0, 0, 0.45), 0 1px 2px rgba(0, 0, 0, 0.3);
  --elevation-3: 0 10px 28px rgba(0, 0, 0, 0.55), 0 2px 6px rgba(0, 0, 0, 0.35);
  --elevation-4: 0 20px 50px rgba(0, 0, 0, 0.75), 0 4px 12px rgba(0, 0, 0, 0.45);
}
```

### В. Световая Фаска (Top Rim Light / Bevel)
Чтобы карточка или кнопка не «тонула» в фоне, верхняя грань подсвечивается физическим микро-бликом:
```css
/* Микро-фаска для карточек и кнопок */
.card-tactile {
  box-shadow: 
    inset 0 1px 0 rgba(255, 255, 255, 0.75), /* Блик сверху для светлой темы */
    var(--elevation-2);
}

:root[data-mode="dark"] .card-tactile {
  box-shadow: 
    inset 0 1px 0 rgba(255, 255, 255, 0.12), /* Деликатный блик в темной теме */
    var(--elevation-2);
}
```

## 4. Прозрачность, Матовое Стекло и Хроматика (Glassmorphism 2026)

Матовое стекло образца 2026 года — это не просто `blur()`, а высококонтрастная поверхность с оптическим насыщением:

```css
/* Эталонная стеклянная панель (Apple Liquid Glass) */
.glass-panel {
  background: color-mix(in srgb, var(--card) 82%, transparent);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid color-mix(in srgb, var(--ink) 7%, transparent);
}

:root[data-mode="dark"] .glass-panel {
  background: color-mix(in srgb, var(--card) 75%, transparent);
  border: 1px solid rgba(255, 255, 255, 0.10);
  backdrop-filter: blur(24px) saturate(190%);
}
```

## 5. Искусство Современных Градиентов (Mesh & Aura Gradients)

Плоские линейные градиенты двух цветов (из синего в красный) выглядят дешево. В 2026 году применяются:

### А. Фоновая Аура (Radial Mesh Glow)
Фон страницы оживает за счет мягких радиальных световых пятен («ауры»), которые двигаются в унисон с темой:
```css
:root {
  --bg-aura: 
    radial-gradient(110% 85% at 5% 5%, color-mix(in srgb, var(--theme-accent) 12%, transparent) 0%, transparent 55%),
    radial-gradient(90% 70% at 95% 95%, color-mix(in srgb, var(--theme-secondary) 10%, transparent) 0%, transparent 60%),
    linear-gradient(180deg, var(--paper) 0%, color-mix(in srgb, var(--paper) 90%, var(--theme-accent)) 100%);
}
```

### Б. Тактильный Градиент Кнопки (Physical Light Falloff)
Кнопка освещается сверху: верхняя часть заливки на 3–5% светлее нижней.
```css
.primary-btn {
  background: linear-gradient(
    180deg,
    color-mix(in srgb, var(--cta) 94%, #ffffff) 0%,
    var(--cta) 100%
  );
  box-shadow: 
    inset 0 1px 0 rgba(255, 255, 255, 0.28),
    0 2px 4px color-mix(in srgb, var(--cta) 25%, transparent),
    0 8px 18px -4px color-mix(in srgb, var(--cta) 40%, transparent);
}
```

## 6. Защитная Вёрстка Без Коллизий (Defensive CSS: Anti-Collision)

Самый частый дефект плохой верстки — наезжающий текст, обрезающиеся кнопки и разорванные сетки при другом размере шрифта.

### 8 Заповедей Защитного CSS:

1. **Никаких фиксированных высот у контейнеров с текстом:**
   - ❌ ЗАПРЕЩЕНО: `height: 48px` на кнопке или плашке с динамическим текстом.
   - ✅ ОБЯЗАТЕЛЬНО: `min-height: 48px; height: auto;` — текст может перенестись на 2 строки и ничего не сломается.

2. **Защита Flexbox от выталкивания и сжатия (`flex-shrink: 0`):**
   - Все иконки, стрелочки, аватары и статусные бейджи обязаны иметь `flex-shrink: 0`. Иначе длинный заголовок сожмет иконку в овал.
   ```css
   .card-icon, .avatar, .badge {
     flex-shrink: 0;
   }
   ```

3. **Борьба с переполнением Flex-детей (`min-width: 0`):**
   - По умолчанию flex-элементы имеют `min-width: auto`. Если внутри лежит длинное слово без пробелов, оно разорвет карточку.
   ```css
   .card-body, .flex-text-column {
     min-width: 0; /* Разрешает сжатие и работу text-overflow */
     overflow-wrap: anywhere;
   }
   ```

4. **Аккуратное многострочное обрезание (Line-Clamping):**
   ```css
   .title-clamp-2 {
     display: -webkit-box;
     -webkit-line-clamp: 2;
     -webkit-box-orient: vertical;
     overflow: hidden;
   }
   ```

5. **Защита Grid-колонок от вылетания (`minmax(0, 1fr)`):**
   - ❌ ЗАПРЕЩЕНО: `grid-template-columns: repeat(2, 1fr)`.
   - ✅ ОБЯЗАТЕЛЬНО: `grid-template-columns: repeat(2, minmax(0, 1fr))`. Без `minmax(0, ...)` сетка ломается при появлении длинного текста.

6. **Изоляция стека наложения (`isolation: isolate`):**
   - На карточках, модалках и плавающих кнопках задавать `isolation: isolate`, чтобы их внутренние `z-index` никогда не конфликтовали с глобальными модалками.

7. **Плавная масштабируемая типографика (`clamp`):**
   ```css
   /* Шрифт идеально адаптируется от маленьких экранов к планшетам */
   h1, .hero-title {
     font-size: clamp(22px, 5.5vw, 32px);
     line-height: 1.15;
     letter-spacing: -0.035em;
   }
   ```

8. **Анти-дребезг чисел (`tabular-nums`):**
   - Любые таймеры, секундомеры, балансы, счетчики валют и проценты обязаны иметь:
   ```css
   .num-metric, .money, .timer {
     font-variant-numeric: tabular-nums;
     font-feature-settings: "tnum";
   }
   ```

## 7. Тактильная Микро-Интерактивность (120 FPS Motion)

* **Физический отклик на тап (`:active`):**
  ```css
  .btn-tactile:active, .card-interactive:active {
    transform: scale(0.97) translateY(1px);
    transition: transform 70ms cubic-bezier(0.2, 0, 0, 1);
  }
  ```
* **Пружинящее открытие шторок (Spring Easing):**
  ```css
  .sheet {
    transition: transform 240ms cubic-bezier(0.16, 1, 0.3, 1), opacity 200ms ease;
  }
  ```
* **GPU-Only:** Анимируются исключительно `transform` и `opacity`. Никаких анимаций `height`, `margin`, `padding`.

## 8. Итоговый Чек-Лист Дизайнерского Качества Перед Сдачей

Перед презентацией любого экрана или фичи инспектируются 8 пунктов:
1. [ ] **Отступы:** Все отступы и зазоры кратны 4px/8px?
2. [ ] **Радиусы:** Вложенные элементы визуально концентричны ($R_{inner} = R_{outer} - P$)?
3. [ ] **Тени:** Тени многослойные (3+ слоя) с цветным подмешиванием и верхней световой фаской?
4. [ ] **Защита от наездов:** На длинных названиях элементы не перекрывают друг друга (`min-width: 0`, `flex-shrink: 0`)?
5. [ ] **Кликабельность:** Хитбоксы кнопок и иконок $\ge 44 \times 44\text{px}$?
6. [ ] **Контрастность:** Текст и иконки четко читаются (WCAG AA $\ge 4.5:1$)?
7. [ ] **Тёмная тема:** Нет ли слепящих белых пятен или грязного серого пластика?
8. [ ] **Тактильность:** Есть ли упругий отклик при нажатии на интерактивные блоки?
